# Original Jot fonts

Jot Sans and Jot Script are drawn from original procedural geometry. Their
outlines are not traced, modified, or renamed versions of the bundled legacy
fonts. The font sources and generated font software in this directory use the
[SIL Open Font License 1.1](OFL.txt); this does not assign a project-wide license.

Jot Sans is a warm geometric family drawn as neatly handprinted pen letters.
Both families use the same almost even circular gel-pen nib, rounded terminals,
small deterministic stroke variation and gentle terminal pooling. Sans retains
geometric spacing and optically heavier UI strokes without baseline wobble.
Script has three visual tip presets: **0.5**, **0.7**, and
**1.0**. These describe the visual feel, not a guarantee of a physical printed
line width or a Pilot-manufactured typeface. Every family has original regular
400 and bold 700 outlines; bold is not browser synthesis.

## Build and serve

Use Python 3.12 and the pinned tools:

```sh
python3 -m pip install -r fonts/requirements.txt
npm run fonts:build
```

The root command builds the package and synchronizes its assets to the parser,
website and extension copies. `python3 fonts/build.py` generates this package
only. Ordinary site serving has no Python dependency and fetches no external
fonts. `python3 fonts/build.py --check` compares every generated byte, including
the list of generated files, without rewriting anything.

```sh
python3 fonts/test.py
npm run fonts:check
```

The full site and editor remain the existing plain JavaScript/CSS application.
No Vite, TypeScript, Tailwind, server, or browser font compiler is required.

## Geometry and compilation

`design_sans.py` and `design_script.py` contain the original letter and figure
centerlines. `build.py` adds punctuation, mathematical signs, currencies and
Western European letters. Accented forms are built from base letters and
original accent vectors; combining accents have zero advances and attachment
anchors. The designs use 1000 units/em, a 700-unit cap-height guide, and a
500-unit x-height guide. Round stroke overshoots are deliberate. Vertical font
metrics include the actual accent, loop and descender bounds.

The compiler expands centerlines with a round nib, unions overlapping parts,
converts conic/cubic segments into TrueType quadratic outlines, and serializes
WOFF2 through FontTools/Brotli. Outlines remain closed SVG paths, never embedded
rasters or SVG text. Both families have restrained per-stroke width variation of at
most 1.5%, and exposed terminal pooling of 5% at every open pen movement; joining anchors are excluded.
There are no sharp brush tapers, flat nibs, texture masks, or transparent ink.

The repertoire includes printable ASCII, Latin-1 Supplement, Œ/œ/Ÿ, dotless i,
the euro sign, smart quotes, dashes, ellipsis, bullets, and common combining
accents. Controls do not become visible glyphs. Nonbreaking space and soft
hyphen retain their whitespace/discretionary roles. Unsupported scripts remain
ordinary editable Unicode and can use the application's fallback fonts.

`liga` supplies ff/fi/fl/ffi/ffl. Script `calt` selects real initial, medial and
final vectors, including accented letters and ligatures; `curs` keeps their
entry/exit anchors aligned. Sans `calt` uses a reduced f terminal before closing
punctuation. GPOS also includes optical kerning and combining-mark attachment.
The script must be shaped as intact words: per-character DOM wrappers or
letter-spacing would disrupt joining. Static outlines encode predetermined pen
shapes; they do not simulate changing physical ink or live pressure.

## Generated contract

`generated/` contains eight WOFF2 files, their feature source, one SVG per glyph,
the font license, SHA-256 checksums and `catalog.json`. Each catalog face provides
its ID, family, visual profile, weight, filename, units/em, vertical metrics and
glyph list. Each glyph includes its name, Unicode or null for an unencoded
alternate, **font-y-up** SVG path, bounds, advance, side bearings, and optional
entry/exit anchors. Standalone SVGs flip that geometry only for presentation.

The inspector consumes this catalog directly. Open the site's **Fonts** page to
compare glyphs, metrics, weights and tip profiles. Its rendered text uses the
compiled WOFF2 face, while its vector panel shows the matching TrueType outline.

Builds use fixed metadata/timestamps, deterministic glyph ordering, seeded
variation and pinned tools. Tests cover the full cmap, closed contours, metrics,
real OpenType shaping, every lowercase joining pair, NFC/NFD accent equivalence,
combining marks, distinct weights/profiles, licenses and byte-identical builds.
Browser tests additionally check real font loading, editor interaction, exports,
the inspector, and highlight readability; compilation alone is not an aesthetic
or accessibility assessment.

## Stroke refinement from pen references

The supplied G2 writing comparisons guide relative visual weights: fine stays
light, medium is restrained, and broad is substantially inkier. Version 1.001
uses 40/52/78-unit Script nibs, scales dots and punctuation with each nib, and
softens exposed starts and endings of every stroke while protecting joining
anchors. Sans receives the same terminal treatment. These are visual design
choices from photographs, not calibrated measurements of physical pen lines.
