## Claude Code

Shared project guidance lives in `AGENTS.md` (above) and in `parser/AGENTS.md`, `site/AGENTS.md` and `vscode/AGENTS.md`, which Claude Code loads through the `CLAUDE.md` beside each. Edit those files, not this one, for anything Codex should also follow; keep only Claude-specific setup here.

`.claude/settings.json` adds:

- A Stop hook (`.claude/hooks/check-generated.mjs`) that runs `node tools/check-generated.mjs` when Claude finishes a turn with changes. If it reports a stale file, regenerate it as `AGENTS.md` describes.
- A PreToolUse hook (`.claude/hooks/guard-generated.mjs`) that refuses edits to generated files and copies and names the source to change.
- A SessionStart hook (`.claude/hooks/session-start.sh`) that runs `npm install` in cloud sessions, for the linter and browser suites.
- A deny rule for `.ics` calendar files (personal data).

Project skills: `.claude/skills/to-jot` and `.claude/skills/methods-research` are symlinks to `.agents/skills/` (the location Codex reads; Claude Code reads only `.claude/skills/`, and follows the link). Edit the skills there, not through a copy.

The methods research (`docs/methods/`) loads only when needed, not in every session:

- The `methods-research` skill (`.claude/skills/methods-research`, a symlink to `.agents/skills/methods-research`) is listed by its description and loads when a decision touches methods, privacy, sharing, health data, safety, reminders, accessibility or tone. It reads `docs/methods/README.md` and then only the guides that bear on the question.
- `.claude/rules/methods-research.md` loads automatically when Claude opens a file where those decisions are made (profiles, the specification, `DECISIONS.md`, proposals, guides, health/voice/music modules, the writer and editor) and points to the skill and the guides most relevant to each area.

The catalogue in `docs/methods/README.md` is generated by `node tools/build-methods-index.mjs`; the rest is written by hand.

`/verify` runs the full verification list from `AGENTS.md`. Put personal notes in `CLAUDE.local.md` (gitignored).
